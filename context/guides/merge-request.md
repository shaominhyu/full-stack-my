# 怎样准备并提交 PR/MR？

适用于本仓库向 GitHub 或 Gitee 提交任务分支。创建工作树、选择检查项、撰写 PR/MR 和核对目标分支时，从下列手册进入。

| 阶段 | 当前做法 |
| --- | --- |
| 选定目标 | GitHub 使用远程 `github`，Gitee 使用 `origin`，两者的目标分支均为 `master`。用 `git remote -v` 对照当前克隆的远程地址，按目标仓库选择基线和推送位置。 |
| 开发与验证 | 按 Worktree 手册创建或复用任务工作树，按质量检查手册选择与改动相符的检查。涉及项目脉络时，核对来源，修改检查器时再跑对应测试。记录实际结果。 |
| 提交与交接 | 提交首行和 PR/MR 标题使用 `type(scope): summary`，其中范围可省略。将任务分支推送到目标远程，正文写明改动原因、内容、实际验证结果与未验证项。 |

核验时查看 PR/MR 页面的源分支、目标仓库和目标分支，再对照正文里的检查结果。默认分支、远程映射或质量检查要求变化时，复查这三步及已记录经验里的旧命令。
